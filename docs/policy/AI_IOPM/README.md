# AI-IOPM Policy Module

AI-IOPM is an exploratory policy module within AIRTF. It studies whether AI infrastructure ownership participation can reduce the probability that AI-era productivity becomes permanently disconnected from broad human participation.

This module is not a guaranteed prosperity model, not a replacement for wages, and not a replacement for AIRTF's existing Responsibility Tax, Compute Levy, Sovereign AI Equity, or labor transition architecture.
