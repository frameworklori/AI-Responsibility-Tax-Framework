# Compute Concentration Levy

The Compute Concentration Levy is based not only on profit, but also on control of national compute capacity.

```text
CCI = Top5ComputeProviders / TotalNationalComputeCapacity
```

## Purpose

- reduce compute monopolization
- fund public compute reserves
- support open-source AI infrastructure
- prevent compute feudalism

## Design

The levy should rise with compute concentration, infrastructure dependency, and national reliance on foreign or private inference infrastructure.
