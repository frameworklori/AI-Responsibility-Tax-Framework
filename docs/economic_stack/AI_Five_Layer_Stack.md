# AI Five-Layer Stack

The AI economy has five interlocked layers:

1. Energy Infrastructure
2. Compute and Semiconductor Infrastructure
3. Foundation Models
4. Distribution and Platform Infrastructure
5. Application and Integration Layer

AI oligopoly does not need to look like traditional monopoly. The risk is cross-layer control.

An actor does not need to fully monopolize any single layer if it controls enough of the stack to create dependency.

Development-stage concentration may be tolerated temporarily, but deployment-stage dependency must be prevented.
