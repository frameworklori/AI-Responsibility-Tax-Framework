# Integration-Layer Monopoly

Integration-layer monopoly occurs when a company dominates not by owning one layer completely, but by integrating several layers into a dependency chain.

## Absorption Channels

- talent
- ideas
- startups
- APIs
- compute access
- user distribution
- infrastructure dependency

## Why It Matters

The integrator becomes the default route through which AI productivity reaches the economy. Smaller firms may build products, but their distribution, inference, model access, and customer acquisition can remain dependent on the integration layer.

## Policy Signals

- rapid acquisition of promising startups
- exclusive cloud/model distribution bundles
- API dependency concentration
- compute discounting tied to platform lock-in
- app ecosystem rules controlled by model or cloud owners
