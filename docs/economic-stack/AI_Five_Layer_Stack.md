# AI Five-Layer Stack

AI economy should be understood as five interlocked layers:

1. Energy infrastructure
2. Compute and semiconductors
3. Foundation models
4. Platforms and distribution
5. Applications and agents

AI oligopoly does not look like traditional monopoly. The risk is cross-layer control.

A company does not need to monopolize one layer completely. It can dominate by controlling several layers at once: compute access, model APIs, developer platforms, distribution channels, and user relationships.
