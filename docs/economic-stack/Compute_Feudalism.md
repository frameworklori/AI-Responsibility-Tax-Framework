# Compute Feudalism

Compute feudalism describes a future where most people and companies do not own AI productivity infrastructure, but rent access from a few dominant infrastructure owners.

## Symptoms

- high Compute Concentration Index
- limited sovereign compute
- API lock-in
- model access gatekeeping
- platform-controlled distribution
- public services dependent on private inference

## Prevention

- public AI infrastructure
- open-source model support
- local inference capacity
- national AI cloud
- public compute reserve
- interoperability requirements
