# Open Source Anti-Feudalism Limits

Open-source AI is useful as anti-feudal infrastructure, but it is not automatically sufficient.

## Risks

- corporate open-source can be strategic
- open models may still depend on private compute
- open ecosystems can be outpaced by closed frontier models
- dominant platforms can absorb open-source gains
- open-source can commoditize competitors without democratizing ownership

## Policy Need

- public compute support
- sovereign open ecosystems
- open model evaluation infrastructure
- non-corporate governance models
- local inference capability
- public-interest AI deployment
