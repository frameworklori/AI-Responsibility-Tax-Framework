# AI Layered Value Extraction Model (ALVEM)

ALVEM evaluates how value is extracted across the AI economic stack.

## Factors

- monopoly intensity
- social externalities
- infrastructure dependence
- profit density
- labor replacement scale

## Example Matrix

| Layer | Profit Density | Monopoly Risk | Social Impact |
|---|---|---|---|
| Energy | High | High | National |
| Compute | Extreme | Extreme | Global |
| Models | High | Medium | Global |
| Platforms | Extreme | Extreme | Civilization-scale |
| Applications | Variable | Low | Local |

## Use

ALVEM can guide differentiated fiscal treatment. A compute monopoly and a small local AI application should not have the same responsibility profile.
