# 模擬情境 — AIRTF 模型場景  
### AI 責任稅框架（AIRTF）  
### 版本：1.0

此資料夾包含用於評估 AI 責任稅框架（AIRTF）全球財政影響的 **政策模擬資料集** 以及 **Python 腳本**。  
模擬模型描述不同區域因 AI 帶來的經濟變化，透過三個主要變數：

- **P — AI 產業利潤**
- **U — 自動化造成的失業影響**
- **E — 訓練模型與運算所需的能源消耗**

這些輸入讓 AIRTF 可以計算責任稅（RT）、再分配結果，並進行跨區域比較。

# 🌍 模擬情境的目的

`country-scenarios/` 中的檔案並非真實財務資料，而是基於政策模型的估算，來源於：

- 區域 AI 產業的結構  
- 運算採用速度  
- 勞動市場的脆弱性  
- 能源 / 電網限制  
- 前沿模型開發能力  

因此這些資料適合用於 *白皮書、政策建模、學術示範與敏感性分析*。

---

# 🧩 AIRTF 在所有模擬中使用的核心公式

\[
RT = \alpha P + \beta U + \gamma E
\]

其中：

| 變數 | 含義 |
|------|------|
| **P** | AI 產業或整合 AI 的部門所產生的年利潤 |
| **U** | 職位流失的經濟成本 → 再培訓、轉職補助、工資差距 |
| **E** | 能源消耗或由運算導致的碳成本 |
| **α, β, γ** | 政策係數 — 可依各國調整 |

---

# 🔎 數值估算方式

每個區域採用不同的結構性邏輯，以反映其經濟與科技面貌。

---

## 🇺🇸 美國 — 高 AI、重運算模型

美國情境假設：

- AI 企業利潤龐大（OpenAI、Anthropic、Google、Meta、xAI 等）
- 由於自動化快速，造成較高的失業衝擊
- 前沿模型訓練導致非常高的能源消耗
- β（勞動影響）與 γ（運算碳成本）較大

📌 結果：**P 高、U 高、E 高**

---

## 🇪🇺 歐盟 — 注重永續導向的模型

歐盟情境假設：

- AI 企業利潤為中等  
- 自動化較慢、勞動保護較強  
- 對碳足跡高度敏感 → γ 較大  
- 強調綠色運算過渡  

📌 結果：**P 中等、U 較低、γ 較高**

---

## 🌏 亞洲 — 混合型經濟模型

亞洲包含高度科技化國家（日本、韓國、新加坡）與新興經濟體（東南亞製造業），數值反映：

- 中高程度的 AI 採用  
- 製造業自動化影響較高 → U 上升  
- 運算能源消耗為中等  

📌 結果：**P 混合、U 中高、E 中等**

# 🖥️ 執行模擬

1. 安裝相依套件：
```bash
pip install pandas
```

2. 執行腳本：
```bash
python airtf_simulation_example.py
```

3. 輸出包含 RT 與再分配結果：

- 40% → 勞動力轉型基金（Workforce Transition Fund）  
- 30% → 精簡型基本所得（UBI-lite）  
- 30% → 綠能與基礎建設基金（Green & Infrastructure Fund）

每個情境檔案會產生完整的財政輸出表格。
